# Israel's Portfolio

A personal portfolio website introducing Israel, an NJIT Software and Data Engineering Technology student. It presents education, interests, projects, technologies, and contact information.

## Links

- **Live website:** [https://ig229-svg.github.io/Portfolio/](https://ig229-svg.github.io/Portfolio/)
- **GitHub repository:** [https://github.com/ig229-svg/Portfolio](https://github.com/ig229-svg/Portfolio)

## View Locally

Download or clone the repository, then open `index.html` in a web browser. The site uses relative file paths and does not require a build step or package installation.

## Pages

- **Home:** A welcome page with an introduction and links to the rest of the portfolio.
- **About Me:** Background, education, interests, and professional experience information.
- **Projects:** An overview of the Smart Parking System, Python News Aggregator, and Car-Mounted Phone Holder projects.
- **Skills:** Technologies and tools grouped by area.
- **Contact:** Email and GitHub profile links.

## Technologies

- **HTML5:** Semantic page structure and content.
- **CSS3:** Responsive layouts, shared visual styling, and dark/light themes.
- **Vanilla JavaScript:** Mobile navigation menu and theme toggle.
- **GitHub Pages:** Hosting for the live website.
