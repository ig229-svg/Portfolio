
# AGENTS.md

## Project Overview
Build a personal portfolio website for Israel, an NJIT Software and Data Engineering Technology student.

The purpose of the website is to showcase education, programming skills, personal projects, and professional experience.

The website must contain five pages:
1. Home (index.html)
2. About Me (about.html)
3. Projects (projects.html)
4. Skills (skills.html)
5. Contact (contact.html)

## Design Requirements
- Use a modern, professional developer portfolio design.
- Use a dark navy background.
- Primary colors: navy (#0B1120), blue (#3B82F6), and purple (#8B5CF6).
- Use white and light gray for readable text.
- Use a clean sans-serif font.
- Include subtle hover effects and smooth transitions.
- Keep the design consistent across all five pages.
- Make the website visually appealing without overcrowding it.

## Website Content
- Display name: Israel
- Education: New Jersey Institute of Technology (NJIT)
- Major: Software and Data Engineering Technology
- Email: ig229@njit.edu
- GitHub: https://github.com/ig229

Include these projects:
1. Smart Parking System

Only use accurate information. Do not invent employment achievements, project results, or technical experience.

## Technical Rules
- Use plain HTML5, CSS3, and vanilla JavaScript only.
- Do not use React, Vue, Bootstrap, Tailwind, or other frameworks.
- Do not use npm or build tools.
- Do not use a backend, database, or login system.
- Do not include API keys, passwords, or tokens.
- All pages must work by opening index.html directly.
- Use relative paths for local files.
- Use an external CSS stylesheet.
- Use an external JavaScript file.
- Use semantic HTML5 elements.
- Include exactly one main h1 heading per page.

## Responsive Design
- Support desktop, laptop, tablet, and mobile screens.
- Use CSS media queries.
- Include a responsive hamburger navigation menu.
- Ensure navigation works on touchscreens and keyboards.
- Prevent horizontal scrolling on mobile.

## JavaScript Requirements
Include at least two interactive features:
1. Responsive mobile navigation menu.
2. Dark/light mode toggle.

Use vanilla JavaScript and keep the code understandable for a beginner.

## Accessibility
- Include descriptive alt text for meaningful images.
- Use proper heading hierarchy.
- Ensure sufficient color contrast.
- Include visible keyboard focus indicators.
- Use accessible labels for buttons and form inputs.
- Support keyboard navigation.
- Use appropriate ARIA attributes when necessary.

## Git Requirements
- Complete one development task at a time.
- Review existing files before making changes.
- Do not unnecessarily rewrite working code.
- After each completed task, summarize the changes.
- Commit each completed task using a clear commit message.
- Push commits to the main branch after the user reviews and approves.
- Never use force push or git reset.
- Do not overwrite unrelated user changes.

## Important Instructions
- Keep the code simple and beginner-friendly.
- Explain important HTML, CSS, and JavaScript changes.
- Test each page after making changes.
- Do not use placeholder text in the finished website.
- Do not publish private information such as phone numbers or home addresses.
- Keep images under 500 KB whenever possible.
- Do not claim that tests passed unless they were actually performed.
